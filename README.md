## English

**MeshCom Map** is a web map for the [MeshCom](https://icssw.org/meshcom/) amateur-radio LoRa
mesh network. It shows nodes, link quality by SNR, messages, weather telemetry and RF
coverage on an interactive map.

**Live app: <https://meshmap.oevsv.at>**

The map is developed by Martin, DK5EN, in cooperation with ÖVSV, who provide the server
it runs on. The data comes from the MeshCom project and is kindly made available by
Kurt, OE1KBC.

### Report a problem / suggest a feature

Please use the [Issues tab](../../issues) of this repository.

**What belongs here:**

- Bugs in the map (something is broken, crashes, renders wrong)
- Wrong or missing data on the map
- Feature ideas
- Questions about what something on the map means

**What does NOT belong here:**

- **MeshCom firmware bugs** — these belong to the MeshCom project, not here.
- **"Remove my node from the map"** — the map only mirrors what the mesh broadcasts openly
  over LoRa. Removal has to happen on the MeshCom side; the map cannot and does not filter
  it.
- **General MeshCom network/gateway operation questions** — please ask the MeshCom
  operators.

**What makes a good report:**

- Callsign(s) involved
- Which tab: Map / Connections / Messages / WX / WX Map / Admin
- What you saw vs. what you expected
- Time, including timezone
- Browser and whether you were on desktop or mobile
- A screenshot, or a deep link, e.g. `https://meshmap.oevsv.at/?focus=CALLSIGN`

### Source code

The source code lives in a private repository. This tracker is issues-only — there are no
pull requests to review here.

A user manual for the map is published at <https://dk5en.github.io/map/>.

## Ελληνικά

Το **MeshCom Map** είναι ένας διαδικτυακός χάρτης για το ερασιτεχνικό ραδιοδίκτυο mesh LoRa
[MeshCom](https://icssw.org/meshcom/). Απεικονίζει κόμβους, ποιότητα ζεύξης βάσει SNR,
μηνύματα, τηλεμετρία καιρού και κάλυψη ραδιοσήματος σε έναν διαδραστικό χάρτη.

**Εφαρμογή σε ζωντανή λειτουργία: <https://meshmap.oevsv.at>**

Ο χάρτης αναπτύσσεται από τον Martin, DK5EN, σε συνεργασία με την ÖVSV, που παρέχει τον διακομιστή στον οποίο λειτουργεί. Τα δεδομένα προέρχονται από το έργο MeshCom και διατίθενται ευγενικά από τον Kurt, OE1KBC.

### Αναφορά προβλήματος / πρόταση λειτουργίας

Χρησιμοποιήστε την καρτέλα [Issues](../../issues) αυτού του αποθετηρίου.

**Τι ανήκει εδώ:**

- Σφάλματα στον χάρτη (κάτι είναι χαλασμένο, καταρρέει, εμφανίζεται λανθασμένα)
- Λανθασμένα ή ελλείποντα δεδομένα στον χάρτη
- Ιδέες για νέες λειτουργίες
- Ερωτήσεις σχετικά με το τι σημαίνει κάτι στον χάρτη

**Τι ΔΕΝ ανήκει εδώ:**

- **Σφάλματα firmware του MeshCom** — αυτά ανήκουν στο έργο MeshCom, όχι εδώ.
- **«Αφαιρέστε τον κόμβο μου από τον χάρτη»** — ο χάρτης απλώς αντικατοπτρίζει ό,τι το
  δίκτυο mesh εκπέμπει ανοιχτά μέσω LoRa. Η αφαίρεση πρέπει να γίνει από την πλευρά του
  MeshCom· ο χάρτης δεν μπορεί, ούτε φιλτράρει κάτι τέτοιο.
- **Γενικές ερωτήσεις για τη λειτουργία δικτύου/gateway του MeshCom** — απευθυνθείτε στους
  χειριστές του MeshCom.

**Τι κάνει μια αναφορά καλή:**

- Εμπλεκόμενα διακριτικά κλήσης
- Ποια καρτέλα: Map / Connections / Messages / WX / WX Map / Admin
- Τι είδατε σε σχέση με το τι περιμένατε
- Ώρα, συμπεριλαμβανομένης της ζώνης ώρας
- Ο φυλλομετρητής και αν χρησιμοποιούσατε υπολογιστή ή κινητή συσκευή
